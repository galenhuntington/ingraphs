The files in this directory provide Bash instructions to verify that
the published DUIs are the only possible ones.  The steps include lists
of counterexamples that narrow the space down.  I make no claim that
these steps are optimal.  The goal is to provide a reasonably fast
way to reproduce my results.  Time estimates are very rough since
platforms vary considerably.

Proving that a surviving graph is a universal ingraph still requires a
(often long) check.  There is no shortcut there.

A "successors" operation with the final graphs can verify there are
none denser, in cases where this isn't already shown.
